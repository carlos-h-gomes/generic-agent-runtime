# Project truth index

`SOURCE-OF-TRUTH.md` is the first project-specific index read after `AGENTS.md`. It records current identity, official version, architecture profile, authoritative source pointers, active work, material risks, and the last qualified evidence.

It is not a transcript or a copy of every detail. Tasks own work authorization and state; schemas and API specifications own machine contracts; code and tests own verified behavior; decisions own rationale and supersession; technical documentation owns maintainers' operational understanding; the user manual owns user-facing usage.

When the index and a detailed source conflict, stop destructive or incompatible work, inspect the evidence, and reconcile through an authorized task. Absence is an unknown, not proof that existing work is false or may be discarded.

Update the index on changes to project identity, official release, architecture profile, public contracts, authoritative pointers, material risks, or release evidence. Ordinary internal edits do not require a truth-index rewrite unless they change one of those facts.

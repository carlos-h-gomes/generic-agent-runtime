# Changelog

## 8.1.0 - 2026-08-31

- Added evidence-based workspace lifecycle inventory and explicit archive planning; age alone never authorizes archival.
- Added owner-bound `_archives` bundles with canonical plans, manifests, SHA-256 payload records, atomic bounded indexes, move journals, verification, rollback, and collision-safe restore.
- Added default protection for authority, active references, source/build/test paths, release/dependency artifacts, sensitive/live state, links, path escapes, and ambiguous material.
- Added the `core/workspace-hygiene` skill, policy and archive schemas, synthetic round-trip/negative tests, adoption ownership, packaging rules, and maintainer/user documentation.
- Added a concrete internet-facing product security and privacy baseline covering identity, sessions, authorization, request/resource limits, API and business-flow abuse, browser controls, SSRF, uploads, webhooks, dependencies, containment, recovery, and LGPD.
- Expanded the threat model, incident template, release checklist, dated standards, and policy sources with OWASP API Security, the consolidated LGPD, and current ANPD incident and international-transfer rules.
- Added a Windows junction/reparse regression that rejects direct and nested boundary traversal; ordinary symlink creation remains an honestly reported privilege-dependent skip on this host.
- Preserved v8.0 contracts and behavior; installation remains dormant and performs no archival, purge, Git, remote, deployment, or production action.

## 8.0.0 - candidate 2026-08-24

- Made mode and write authorization take precedence over risk-based governance persistence: review-only production assessments stay concise, reuse existing artifacts, and require canonical schema validation for any authorized formal evidence.
- Rebuilt the behavioral runner so the digest-pinned candidate governs an isolated synthetic target; fixture context and task artifacts are materialized, protected control-plane integrity is enforced, and grading requires route, semantic, metric, repeat, configuration, threshold, and cost-baseline evidence.
- Replaced the universal greenfield Python/React assumption with user-owned open architecture profiles while retaining the packaged profile for compatibility.
- Added reuse-first decisions before material new implementation or dependency surface.
- Added vendor-neutral solution components so user-named tools are not limited to code, n8n, or hybrid.
- Generalized architecture validation for layered, feature, mixed, and ecosystem-native profiles with Python and JavaScript/TypeScript composition-root adapters and honest incomplete results.
- Added optional, dated GPT-5.6 Sol and Daybreak Blue capability profiles with access detection, budgets, fallbacks, and evaluation requirements.
- Derived from public v7.0.0 commit `51d1e3b915de0d8c207905e1c7c8ea55c6126120` and verified release SHA-256 `89c0f481006ff85e787bb2f939c46b11c1b7c3be207fe05b39d05437cc51df3b`.

## 5.0.0 - 2026-07-30

### Security assurance

- Added an expiring, official-source-backed security policy with Node and Next.js lifecycle floors.
- Project-owned test, lint, and build scripts require explicit trust and receive a minimized environment by default.
- Added self-contained source, secret-pattern, sensitive-file, runtime/framework, and deployment-boundary checks plus optional dependency advisory scanning.
